# Budget Tracker

A personal budget-tracking web application built with React and Vite.

This project lives in its own directory within the main [AI Engineering Learning Journey](../README.md) repository.

## Technology Stack

- React
- Vite
- React Router
- Chart.js and React Chart.js 2
- Three.js and React Three Fiber
- ESLint

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

From this directory, install the project dependencies:

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal.

### Build for production

```bash
npm run build
```

### Run the linter

```bash
npm run lint
```
